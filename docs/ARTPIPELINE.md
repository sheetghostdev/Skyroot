# Skyroot art pipeline

All 3D art is generated by Python scripts run in **Blender 4.5 LTS** (headless):

```
blender -b --python tools/blender/<script>.py
```

`tools/blender/build_all.sh` regenerates every model.  Scripts import the shared
helpers in `tools/blender/common.py` (palette, geometry builders, vertex-colour
painting, glTF export, Cycles preview renders).  Generated `.glb` files live in
`assets/models/<group>/` and are committed; Godot imports them normally.

## Conventions

* **Units:** metres, real-world scale.  Blender is Z-up; the glTF exporter converts
  to Godot's Y-up (`Blender +Y` becomes `Godot -Z`, i.e. "forward").
* **Colour:** all colour is stored in a linear vertex-colour attribute named `Col`
  (exported as `COLOR_0`).  Materials are white and only *name the surface role*.
  Godot replaces materials by name with its own shaders (wind on leaves, triplanar
  detail on stone, wetness on clay...).  Use the palette in `common.py`; bake
  gentle AO/gradients into the vertex colours.
* **Material role names** (exact): `Bark`, `WoodEnd`, `Wood`, `Leaves`, `Stone`,
  `Moss`, `Skin`, `Cloth` (neutral light grey vertex colour so Godot can tint it per
  player), `ClothDark`, `Leather`, `Hair`, `Rope`, `Straw`, `Daub`, `Plant`
  (stems/crop foliage), `Fruit` (berries, tubers, grain heads, mushroom caps),
  `Soil`, `Clay`, `Charcoal`, `Ash`, `Ceramic`, `Eyes`.
* **Origins:** ground props, plants, trees, rocks and building pieces: bottom
  centre (unless stated).  Hand-held items: geometric centre.  Pivoted parts (tree
  branches, character parts) as specified per model.
* **Style:** stylised, softly rounded, handcrafted.  Organic shapes smooth-shaded
  with gentle noise; rocks with soft facets; wood with slight irregularity.  No
  toy-like perfect primitives, no voxel look, no excessive detail.
* **Budgets:** tree ≤ 15k triangles total, character ≤ 4k, items ≤ 800,
  plants ≤ 1.5k per stage, building pieces ≤ 2.5k.
* **Previews:** every script renders Cycles previews to `tools/blender/previews/`
  (gitignored) for visual review.
